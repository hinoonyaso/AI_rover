# TEST_PLAN: 읽기 전용 운영·센서 대시보드

신뢰 수준: 계획 초안 (2026-11-15). 레벨은 `AGENTS.md`의 정의를 따른다.

| 작업 분해안 | 필요 레벨 | 조건 및 통과 기준 |
|---|---|---|
| 1. 데이터 계약 | L0 | API와 화면의 단위·시각·미수신/만료·오류 의미가 일치하고 기존 8초/10초 기준의 유지 또는 변경 근거가 문서화된다. |
| 2. 상태 화면 | L0 + L1 | 프론트엔드 빌드 성공. 하드웨어 없이 고정된 정상·빈·오래된 스냅샷에서 값과 시각, 미확인 상태가 구분된다. |
| 3. 오류와 복구 | L0 + L1 | 격리 환경에서 API 연결 실패/복구, DB 실패/복구, ROS 모니터 중단, 센서 미수신/만료를 재현한다. 화면에 각 상태가 구분되고 복구 후 최신 값이 나타난다. 서버 실패 시 기존 값이 현재 값인 것처럼 표시되지 않는다. |
| 4. 이력 | L0 + L1 | 가상 또는 격리된 DB의 지표와 이벤트가 표시되고 빈 결과와 DB 실패가 구분된다. 기존 운영 DB에 시험 데이터를 쓰거나 기존 데이터를 삭제하지 않는다. |
| 5. 실행·문서 | L0 + L1 | 관련 테스트와 화면 빌드가 통과하고 localhost 접근을 확인한다. ROS 발행·서비스/액션 호출이나 제어 엔드포인트가 없음을 코드와 실행 범위에서 확인한다. 사용법·한계·결과를 README에 기록한다. |
| 6. 실제 센서 대조 | L2, 장비 사용 가능할 때 별도 | 모터와 팔 구동·토크 변경 없이 수신 가능한 실제 배터리 및 센서의 값/토픽과 화면을 대조한다. 미연결 센서는 미확인으로 표시한다. 대상, 시간, 수신 상태와 결과를 기록한다. 미실행 시 미검증으로 남긴다. |

재부팅, 장시간 및 동시 부하는 이 계획의 하드웨어 없는 완료 조건이 아니다. 수행한다면 별도 조건과 결과를 기록한다. L3~L5 및 물리적 구동은 이 계획에 포함하지 않는다.
