# 음성 개발 환경: 로컬 STT·LLM·TTS와 클라우드 LLM

목표: Jetson 8GB에서 한국어 음성 명령을 녹음·문자 변환하고 로컬 또는 사용자가 선택한 클라우드 LLM으로 텍스트 응답을 생성해 기존 Piper로 재생하는 수동 시험 환경. 외부 전송은 사용자가 기존 클라우드 모드를 선택하거나 auto 모드에서 전송을 명시적으로 허용했을 때만 수행한다. 로봇 동작, DOA, 상시 청취와 자동 폴백은 범위 밖이다.

로컬 Whisper base 다국어 + whisper.cpp, Qwen3 1.7B Q4 + llama.cpp, 기존 Piper KSS를 사용한다. CPU 우선으로 설치해 ROS/GPU와의 경쟁을 제한하고 실제 부하를 측정한다. 클라우드는 무료 등급이 있는 Groq의 OpenAI 호환 Chat Completions 경로를 기본값으로 하되 모델·엔드포인트를 바꿀 수 있게 한다. 계정별 무료 한도·가용성·개인정보 정책은 별도 확인하며 API 키는 Git에서 제외한 `tools/voice/.env`에 둔다. 클라우드 전송은 명시 선택할 때 발화의 텍스트가 외부로 전송된다.

성공 기준: 각 로컬 실행 파일 및 모델이 로드되고 합성 한국어 음성의 STT, 로컬 응답, Piper 출력을 실측한다. 클라우드 설정·요청은 모의 서버로 검증하고 실제 호출은 사용자의 키가 필요하다. ROS 통합 및 주행·인식 동시 부하 결과는 별도 검증 전 미확인이다.

## LangGraph 분기 확장 (2026-11-12)

기존 단발 음성 파이프라인을 보존하고 auto 모드에 LangGraph 상태 분기를 추가한다. 명시적 시각/복잡 단서 우선, 그 외 로컬 LLM 분류; 잘못 분류될 수 있어 경로 수동 선택을 제공한다. 외부 전송은 `--allow-cloud`, 이미지 업로드는 추가로 `--allow-images`를 요구한다. Groq 호환 VLM과 ROS 카메라 단일 프레임을 사용하며 카메라·API 실패는 별도 통보한다. 범위: 음성 답변까지만, 임무·액추에이터 없음. 기존 직접 Python 분기보다 경로 확장이 쉬우나 프레임워크 의존성과 분류 지연이 생긴다. 네트워크·실제 카메라·계정 접근 및 부하 검증은 미완료.
