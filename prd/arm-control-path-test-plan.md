# TEST_PLAN: 팔 제어 경로 확정 + 접촉 파지

PRD: `prd/arm-control-path.md`. 레벨 정의는 AGENTS.md "테스트 레벨과 완료 기준". **"미정(측정 후)"는 해당 측정을 먼저 한 뒤 통과 기준을 확정한다.**
팔을 움직이는 시험은 실행 전에 알리고 사용자 "준비"를 받는다. 서보 온도 80 ℃, 배터리 ≥ 10.5 V를 시험 시작 조건으로 둔다(ready gate).
**T1·T2는 읽기 전용이라 팔을 움직이지 않는다: `arm_command_enabled:=false`, `arm_move_home_on_start:=false`로 기동**(T3 이후 시험의 공통 조건과 다르다).

|---|---|---|---|
| **T1 폴링 벤치마크 (R1)** `arm/servo_stats` + `arm_poll_bench.py` — `arm/servo_stats`의 마지막 응답 시각은 **각 서보 응답 프레임이 실제로 도착한 시각**이어야 하며, 주기적으로 재발행되는 `/joint_states` 헤더 시각으로 대신하지 않는다(그것이 기존 신선도 문제) | L0 단위(통계 계산) + L2 실기(팔 정지, `arm_command_enabled:=false`, 모터 비활성) | 측정 후 확정. 초안: IMU 수신률 저하 ≤ 1 %, 응답 누락 0, `cmd_vel` 지연 증가 없음. 5·12·20(·30) Hz 표를 `docs/benchmarks/`에 기록(12 Hz는 2026-10-06 실기에서 이미 썼으나 정량 측정은 처음) | 문제 있는 속도는 채택 안 함 |

## 재현 조건 (공통)
- 펌웨어 `firmware/rrc_m4`, 로봇은 정지(바닥, 모터 스위치 옆에 사용자). **T3 이후**: base_node `arm_command_enabled:=true`, 팔 홈 자세에서 시작. **T1·T2(읽기 전용)**: `arm_command_enabled:=false`, `arm_move_home_on_start:=false`(팔은 현재 자세 그대로, 홈 이동 없음).
- 시험 기록: 각 시험 회차의 온도·배터리·`arm/servo_stats`를 함께 저장한다.
- 큐브: 3×3×3 cm, 같은 면이 그리퍼 안쪽에 오도록 사용자가 손으로 열린 그리퍼 사이에 놓는다.

## 이 계획에서 하지 않는 것
ros2_control 전환 시험, 3 cm 큐브 외 물체의 파지 프로파일, 인식 연동(7단계), 주행 중 팔 사용.
