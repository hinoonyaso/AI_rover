## 시나리오 (제안, 경로는 S1과 같은 직선 (0.55, 0.40) → (0.55, 1.20) 또는 방 크기에 맞게 조정)
| ID | 장애물 | 움직임 | 기대 동작 |
|---|---|---|---|
| D1 | 사람(다리 두 개) | 로봇 앞 0.6~0.8 m를 0.5 m/s로 가로지름 | 멈춤 → 지나간 뒤 재출발 → 도착 |
| D2 | 사람 | 정면에서 0.3 m/s로 다가오다 옆으로 비켜 지나감 | 멈춤(후진 안 함) → 지나간 뒤 재출발 |
| D3 | 낮은 상자(LiDAR에 안 보임) | 로봇 앞 0.6~0.8 m를 0.3 m/s로 가로지름 | depth로 감지해 멈춤 → 재출발 |
| D4 | 상자가 갑자기 나타남(정지) | 로봇 앞 0.5~0.6 m 경로 위에 순간이동 | 멈춤 → 대기 상한 뒤 옆이동 회피 → 도착 |

## 지표 정의 (정답 기준)
- **접촉**: 로봇 몸 직사각형과 장애물 형상(사람 = 다리·몸통 원, 상자 = 직사각형)의 최소 간격 ≤ 0
- **최소 간격**: 시험 동안 움직이는 장애물과의 최소 간격
- **정지 반응 거리**: 로봇이 멈춘 순간 장애물까지의 간격
- **재출발 지연**: 장애물이 로봇 경로 통로(몸 폭 + 여유)에서 벗어난 시각 → 로봇 속도가 다시 0.03 m/s를 넘는 시각
- **대기 시간**: 정지 누적 시간. D4는 대기 상한 뒤 회피를 시작했는지
- 도착 성공·위치 오차·전체 시간은 8.15와 같은 정의

## 위험과 확인할 점
- 순간이동 반복으로 움직이는 모델은 물리 충돌 반응이 실제와 다르다 → 접촉은 정답 기하로만 판정한다.
- collision_monitor `approach`는 정지 상자 옆 정상 회피를 막은 이력이 있다(2026-10-06) → 정지 상자 회귀를 반드시 같이 본다.
- sim 속도(RTF 0.45)에서는 장애물 속도를 sim 시간 기준으로 맞춘다.
