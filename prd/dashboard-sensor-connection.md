# 대시보드 센서 연결

카메라와 IMU 모니터링을 위해 운영자가 각 드라이버를 명시적으로 시작·종료하고, 프로세스 실행과 데이터 수신을 구분한다. 외부에서 실행 중인 드라이버는 중지하거나 중복 기동하지 않는다. 조회자는 상태만 볼 수 있다.

카메라 서비스는 대시보드 전용 systemd 사용자 서비스이며 자동 시작하지 않는다. 로봇 카메라 구동은 바퀴·팔 명령을 포함하지 않는다. 기존 base_node는 바퀴 명령 구독, 시리얼 전송 및 비상정지 해제 기능이 있으므로 그대로 웹에 연결하지 않는다. IMU 센서 전용 제어는 모터/팔 명령을 구조적으로 차단한 별도 경로를 마련하고 가짜 시리얼 및 격리 ROS 검증 후 제공해야 한다.

하드웨어 모터 및 팔 구동, 외부 프로세스 종료, 보정값 적용은 범위에 포함하지 않는다.
