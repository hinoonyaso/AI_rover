# PRD: AprilTag 정밀 위치 정렬 (체크리스트 10)

- 작성 2026-10-29. 상태: **초안 — 사용자 결정 4개 대기(아래 "결정할 것")**. 결정 전에는 코드를 쓰지 않는다(AGENTS.md 3-File System).
- 신뢰 수준: 계획. 환경 사실(아래 "확인한 것")만 확정.

## 목표
Nav2 + 정밀 접근(`precise_approach`, 지도/AMCL 기준 ±2 cm)은 **지도 좌표**에 대한 정확도다. 실기 AMCL 오차(재위치 전 8~9 cm,
`docs/benchmarks/navigation/real_avoid_20261025.md`)와 지도 자체 오차 때문에 책상·충전대·작업대 같은 **실제 물체** 앞에 정확히 서려면
물체에 붙인 표식을 카메라로 보고 마지막 정렬을 해야 한다. MVP 계획(`docs/PLAN_ARM_TO_MVP.md`)의 "근처 ±10 cm + 카메라 재검출 보정"과
팔 단계의 3D 위치 정답(7단계, 36h11 인쇄 태그)에도 같은 검출기를 쓴다.

## 범위 (제안)
- 컬러 카메라(`/depth_cam/color/image_raw` + `camera_info`)에서 AprilTag 36h11 검출 → 태그 자세(PnP) → TF `camera_color_optical_frame → tag_<id>`.
- 태그 id ↔ 장소 이름 표(예: desk / charger / workstation)와 장소마다 "태그 기준 정차 자세"(태그 앞 d m, 정면)를 설정 파일로.
- 정렬 동작: Nav2(정밀 BT)로 장소 근처까지 → 태그가 보이면 태그 기준 목표 자세를 계산해 정밀 접근으로 마무리.
  재사용 우선: 새 제어기를 만들지 않고 `precise_approach`에 **목표를 태그 기준으로 다시 계산해 넘기는** 방식을 기본안으로 한다.
- 정차 오차 측정 도구(태그 기준 오차 기록 + 줄자 대조).

## 비범위 (지금은 안 함)
- 충전 접점 도킹(전기 연결), 움직이는 태그 추적, 여러 태그 동시 융합으로 AMCL 보정(나중 단계).
- 손-눈 보정(팔 단계 7에서).

## 확인한 것 (2026-10-29)
- Jetson OpenCV 4.6.0에 `cv2.aruco.DICT_APRILTAG_36h11` 있음 → **추가 설치 없이** 검출·PnP 가능.
- `ros-jazzy-apriltag-ros` 3.4.0은 apt 후보만 있고 미설치(설치에 sudo 필요). Jetson·호스트 모두 `apriltag_msgs`만 있음.
- 카메라 드라이버가 `/depth_cam/color/camera_info`를 냄. 내부 파라미터가 공장값인지 보정값인지는 **미확인** — PnP 거리 정확도에 직접 영향.

## 결정할 것 (사용자)
1. **첫 사용처**: (a) 작업대 앞 정차(팔 집기 준비, MVP 경로) / (b) 충전대 / (c) 둘 다 같은 방식으로. — 제안: (a).
2. **검출 라이브러리**: (a) OpenCV aruco 36h11(설치 없음, 직접 노드 작성, 코드 약 200줄) / (b) `apriltag_ros`(표준 노드, apt 설치 = sudo, Jetson 부하 미확인). — 제안: (a), 정확도가 모자라면 (b).
3. **정렬 끝 기준**: (a) 태그 기준 ±2 cm·2°(지금 정밀 접근과 같음) / (b) 더 엄격(±1 cm). — 제안: (a).
4. **태그 설치**: 크기(제안 10 cm 검은 사각형, A4 인쇄)·높이(카메라 0.345 m 근처, 벽/작업대 앞면 세로 부착)·개수.

## 제약
- AGENTS.md 안전 규칙. 실기 정렬 시험은 사용자 입회, 0.06 m/s 이하(정밀 접근 기본값), collision_monitor 경유(`/cmd_vel_nav`).
- 카메라가 팔 근처에 있어 팔 자세에 따라 시야가 바뀐다(depth 홈 자세 게이트, 8.13.4) — 정렬 중 팔은 홈 자세.
- 카메라 최소 거리·시야: 태그가 너무 가까우면(약 0.2 m 이하 추정) 화면 밖 — 정차 거리 d는 0.3~0.5 m에서 시작.

## 완료 기준 (제안)
- L0: 합성 영상(렌더한 태그)에서 id·자세 오차 < 1 cm / 1°, 단위시험.
- L5 sim: Gazebo에 태그 모델을 붙이고 정렬 10회, 정답 대비 ±2 cm·2°.
- L5 실기: 태그 앞 정차 5회, 줄자 ±2 cm, 접촉 0, 사용자 입회.
