# 설비 점검·웹 관제·음성·RAG 시험 계획

작성: 2026-11-19. 시험 목록은 실행 계획이며 통과 결과가 아니다. 구체적인 성능 목표는 기준선 측정 후 기록하고, 임의의 목표치를 기존 성능처럼 주장하지 않는다.

| 단계 | 시험 | 통과 확인 |
|---|---|---|
| 공통 | 기존 테스트·버전·서비스 상태·자원 기준선 | 실행 명령, 환경, 실패 여부 보존. 실제 장치 구동 없음 |
| 점검 | 켜짐/꺼짐·색상 반전·가림·낮은 조도·영상 중단 | 제공된 정답과 색상별 결과 비교; 근거 부족은 판정 불가, 실패 사유·근거 기록 |
| 점검 | 가상 임무 생성→주행→관측→저장·화면 표시 | 각 단계와 결과·타임스탬프 일치, 취소/실패/재시작 이력 보존 |
| 점검 | 독립 실제 영상 | 영상이 준비되면 가상과 별도로 평가; 없으면 미검증 표시 |
| 웹 | 실제 센서 구동 없이 ROS↔API↔화면 대조 | 값·단위·시각 일치, 영상과 장애물 점 수신 구분, 팔 홈 이탈·데이터 만료·복구 표시 |
| 웹 | 격리 DB/ROS/서버 장애와 재시작 | 권한 없는 쓰기 거부, 오류·복구와 재시작 임무 상태 확인, 기존 이력 보존 |
| 웹 | 다른 PC의 LAN HTTPS | 실제 Jetson 주소, 인증서 지문, 로그인·권한과 재접속 확인 |
| RAG | 독립 질문·근거 없음·실시간 질의 | 정답 근거와 출처, 거부·유보를 별도 채점하고 개선 전후 결과 및 오답 기록 |
| RAG | 로컬 모델 대 EXAONE | 동일 질문·문맥, 답변 충실성·오류·출처·지연·비용/전송 조건 비교; 실패와 시간 초과 기록 |
| RAG | 별도 경로 백업·복원 및 장애 | 원본 보존, 복원 색인 질의 일치, 손상/잠금/모델 누락 시 안전한 오류 |
| 음성 | 마이크·VAD·깨우기·STT·TTS | 실제 발화/무음/소음/취소·마이크 단절과 재유입에 대한 인식·오작동·지연 기록 |
| 음성 | 명령 해석→모의 임무·조회·취소 | 허용 명령만 실행, 모호·오인식은 확인 또는 유보, 실제 로봇 명령 0 |
| 통합 | 센서·카메라·웹·DB·검색·음성 동시 부하 | 시험 조건과 시간, 데이터 나이·누락, 오류, CPU/RAM/스왑을 기록하고 기준선 비교 |
| 통합 | 실제 주행·팔·설비 연결 | 앞선 안전 대책과 별도 승인·환경 확인 후 별도 계획으로 수행; 미수행 시 미완료 표시 |

실기 구동과 물리 설정 적용 없이 가능한 시험부터 실행한다. 사용자가 준비해야 하는 실제 영상이나 다른 물리 PC, 별도 승인이 필요한 재부팅·실기 시험은 준비 상태와 관계없이 완료로 표시하지 않는다.

## 2026-11-19 경광등 1차 결과

- 합성 녹화 영상 및 관측기·분류기 테스트 16건 통과: 판정, 짧은 영상, 누락 파일, 표본 제한, 출처별 집계, 근거 이미지 보존, 관측 오류 포함.
- 격리 SQLite 작업자·임무 API·계약 테스트 28건 통과: 유효한 실패 진단 저장, 잘못된 진단은 저장하지 않음, 기존 성공·실패 계약 유지.
- 별도 ROS 도메인 98에서 합성 카메라 영상 중단 후 `inspection_unconfirmed`와 수신·유효 표본 수 확인. 물리 카메라와 로봇은 사용하지 않음.
- Firefox 격리 대시보드에서 모의 임무, 색상 결과 및 실패 진단 표시 확인. Vite 빌드와 렌더링 시험 통과. 실제 운영 임무가 없는 상태에서 대시보드 재시작 후 인증서 검증 HTTPS 200 확인.
- **미검증:** 실제/대체 실물 영상 평가, 녹화 영상 검토 결과·근거의 임무 이력 연결, 실제 설비 판정 및 실기 주행. 합성 시험 통과를 실제 성능으로 환산하지 않는다.
- 출처별 영상 평가기: 합성 영상 5사례(정상·깜빡임·짧은 영상·가림·모호한 밝기), 색상 라벨 15개 모두 예상값과 일치, 그중 5개는 `unknown`. `tools/mission/evaluate_stack_light_synthetic.py`로 재현 가능하며 인위적으로 만든 소규모 사례이므로 실물 정확도 평가는 아니다.
- 별도 임시 MySQL 스키마에서 실패 진단 저장 및 관리자의 재시작 후 복원 확인, 전체 MySQL 임무 테스트 6건 통과. 기존 운영 임무 테이블은 사용하지 않았다.
- 격리 Gazebo에서 점검 중 카메라 브리지 중단: `failed / inspection_unconfirmed`, 수신 10·간격 초기화 6·유효 표본 1이 임무 결과에 저장됨. 브리지 중단은 `/clock`도 함께 영향을 주므로 카메라 단독 장애 시험은 아니다.
- 녹화 영상 검토 API: 운영자 로그인·동일 출처, 최대 8MB·1280×720, 단일 처리·타임아웃 제한을 적용했다. 합성 파일 API 색상 3종·근거 이미지 및 무인증/조회자/다른 출처/초과 크기/잘못된 파일 거부 시험 통과. Firefox 격리 환경에서 합성 파일 업로드·판정·근거 이미지 렌더링 통과. 업로드 영상·결과는 임시 처리하며 임무 이력에는 저장하지 않는다.

## 음성 시제품 구현 검증 (2026-11-19 계획)
- 텍스트·오디오 크기·WAV 형식과 호출어, 무관·위험 명령, 불명확한 취소/중복 확인, 시뮬레이션 외 모드 거부를 단위 및 격리 API에서 검증한다.
- 합성 PCM으로 VAD의 시작·침묵 종료·최대 길이·초기 무음, 전사 모의 성공/오류를 검증한다. 브라우저에서 마이크 권한 실패, 켜기/끄기와 화면 상태를 확인한다.
- 가짜 격리 임무 DB에서 생성→시작, 명시 확인 전 미실행, 취소 및 다중 임무 모호성을 검증한다. 실제 장치/실제 임무는 구동하지 않는다.
- 마이크와 스피커가 실제 연결된 경우 무음·합성 입력 및 단발 장치 연결을 점검하되 사람 발화·실내 소음·재유입 인식률은 수집한 실측 근거가 없으면 별도 미검증으로 남긴다.

### 실행 결과 (2026-11-22)
- 격리 API 4개 테스트: 제한 명령 분류, 운영자 인증·WAV 제한, 인식 중 동시 요청 및 클라이언트 취소 이후 잠금 처리 통과.
- VAD 합성 PCM: 무음, 발화 종료, 최대 길이, 리샘플링 및 WAV 생성 통과. 프런트엔드 빌드 통과.
- 격리 SQLite·Firefox 및 가짜 마이크: 상태 조회·문서 응답·확인 전 미실행·모의 임무 시작/취소·실제 주행 거부·마이크 켜기/끄기 통과. 실제 로봇을 구동하지 않음.
- Piper 합성 발화 4개를 기존 Whisper에 입력한 초기 시험에서 호출어를 모두 정확히 인식하지 못함. 사람 발화, 소음, 에코, 전체 지연 및 오작동률은 미검증. 호출어 검사 전 전사가 필요하며 고정 음량 VAD이므로 조용한 환경에서도 재현성은 보장하지 않는다.
- 운영 HTTPS에 음성 API 반영 후 비인증 요청 403 확인. 실제 사용자 로그인 마이크 발화부터 응답까지의 종단 간 시험은 아직 필요하다.
