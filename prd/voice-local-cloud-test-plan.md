# 음성 개발 환경 시험

- L0: 비밀키 누락 오류, 백엔드 선택, 입력/경로 검증과 모의 클라우드 요청 검증. 키값을 로그에 출력하지 않는다.
- L1: 한국어 Piper 음성 WAV로 whisper.cpp 다국어 모델 전사, 로컬 LLM 응답 및 지연·메모리 확인. CPU 실행임을 기록한다.
- L2: 사용자 허용 시 마이크→STT→LLM→TTS의 수동 왕복. 키가 없는 상태에서 클라우드 실제 호출은 미실시.
- L3: Nav2·카메라·DOA 동시 실행 및 ROS 통합은 별도 시험 전 미완료. API 결과를 직접 로봇 구동 명령으로 사용하지 않는다.

## LangGraph 분기 확장

- L0/L1: 규칙·로컬 분류, 전송 허용 게이트, 예외, 실제 SDK 모의 요청 및 기존 회귀 시험.
- L2: Jetson 로컬 auto 대화, 분류 시간과 출력 확인.
- L3 미완료: API 키 입력 후 텍스트 LLM 및 VLM 실제 요청과 오류·한도 확인.
- L4 미완료: ROS 카메라 실행 후 사진 전송과 사용자 음성 왕복, 로봇 동시 부하 측정. 주행·팔 구동 제외.
