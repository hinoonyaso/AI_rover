# 대시보드 LAN 직접 접속

2026-11-17 사용자는 SSH 터널 없이 다른 PC에서 웹 관제에 로그인하도록 요청했다. Wi-Fi IPv4 `172.30.1.82`에만 TLS 서버를 바인딩하고 `172.30.1.0/24` 클라이언트와 정확한 Host를 허용한다. 다른 인터페이스나 비HTTPS 요청은 허용하지 않는다. 관리자·조회자 권한, 동일 출처 검증, 실제 로봇 제어 거부를 유지한다. 리버스 프록시 헤더는 신뢰하지 않는다.

인증서는 Jetson에 생성한 자체 서명 인증서이며 첫 접속 PC에서 인증서 지문 확인과 신뢰 설정이 필요하다. 인증서 개인 키와 계정 정보는 사용자 전용 파일에 저장한다. IP가 바뀌면 현재 설정과 인증서의 주소가 일치하지 않으므로 관리자 재설정이 필요하다. 기존 로컬 HTTP service 파일은 적용 전 백업했다.

검증: 인증서를 신뢰한 HTTPS 클라이언트에서 LAN IP 접속·viewer/operator 로그인·쓰기 권한 차이·교차 출처 거부 확인, Firefox LAN 주소 로그인 및 viewer 쓰기 버튼 비활성 확인, 허용 외 IP·Host·HTTP 거부 단위 시험. 서로 다른 물리 PC에서의 실제 통신과 해당 PC의 인증서 신뢰 설정은 사용자 환경에서 아직 확인하지 않았다.
