## 2026-11-17 결과
기존 후보 호환·신규 이력, 원자 교체 실패 시 기존 파일 보존, 11종 ID, 비대칭 외형 후보·값 범위, 배터리 표본 최신성·오차 계산 및 권한 등 총 9건 통과. 격리 Firefox에서 목록·예정 표시·외형 및 전압 비교 입력 화면을 확인했다. 실제 실측과 Nav2 반영은 하지 않았다.

- LiDAR 위치 후보: 양·음 좌표의 cm→m 변환, 프레임 명시, 비유한값/범위 초과/불리언 거부, 측정 중 충돌 및 조회자 쓰기 거부를 격리 테스트한다. 실제 원점·각도·스캔 비교는 실기 검증 전 미확인이다.

- 오도메트리 비교: 전진/횡이동 cm 및 누적 회전 deg의 부호, 오차와 실측 절댓값 기준 백분율, 출처, 0 기준·비유한값·범위·권한 거부를 격리 테스트한다. 수동 기록의 원본 일치와 실제 정확도는 사용자 확인이 필요하다.

- 휠 관찰 기록: 시뮬레이션/실기 구분, 네 바퀴 각각의 관찰값과 미확인 보존, 잘못된 값 및 조회자 쓰기와 다른 측정 중 저장 거부를 검사한다. 실제 회전 방향과 속도는 검증하지 않는다.

- 카메라 정보: 가짜 ROS 도메인의 CameraInfo 구독·저장과 유효한 컬러 정보 제공 및 깊이 미수신을 확인한다. NaN·영 초점거리·손상 및 오래된 상태와 미래 수신 시각은 배제한다. 실제 장치 QoS와 발행 내용은 미검증이다.

- 카메라 비교: 같은 해상도 행렬의 네 항목 차이, 다른 해상도·비정상 행렬·NaN·영 초점거리 거부를 테스트한다. 장치 동일성과 정확도는 별도 검증이다.

- RGB-D 대응점 비교: 최신 CameraInfo 요구, 해상도·프레임 일치, 좌표 범위와 RMS 계산·조회자 거부. 실제 수신된 CameraInfo 복사와 합성 점으로 별도 저장소에서 연동 확인; 실제 점과 동기 영상은 미검증.

- 팔 관절: 격리 ROS에서 파라미터 읽기·관절 구독·서보 진단 경과 시각을 결합하고, 오래되거나 응답 없는 서보는 비교를 거부한다. 실제 장치는 센서 전용으로 관절 발행이 꺼져 있어 실기 확인 전이다.

- 고정 자세 강체 변환: 합성 회전·이동 복원 및 일직선 데이터 거부. 실제 좌표·다중 자세 핸드아이 검증은 별도다. 자이로 파일 적용은 임시 파일에서 백업·복원, 후보와 설정 변경 감지, 중복 설정·심볼릭 링크·실패 보존·조회자 권한을 검증한다. 실제 설정은 변경하지 않았다.

- 핸드아이: 서로 다른 6개 합성 자세와 알려진 link4→camera 변환 복원, 고정 표적 잔차, 회전 다양도 부족 및 비강체 행렬 거부. 실제 하드웨어 자세의 동기와 정확도는 미검증이다.

## 2026-11-17 후속 검증

- 가상 시리얼·격리 ROS: 기본 센서 전용 모드 송신 0, 팔 관측 모드 위치·온도 읽기만 21회 및 6관절 수신; 바퀴·팔·토크 구독과 구동 프레임 0.
- 실제 읽기: 팔 관측 모드에서 6관절 신선한 응답과 TCP TF 자세 수집 3회. 보정 중 로봇 움직임 및 실제 보정값 적용은 하지 않음.
- 핸드아이·LiDAR 위치/각도·TCP 등의 설정 검토, 임시 파일 적용·복원과 충돌 거부 및 화면 빌드. 실제 설정 적용 및 독립 정확도 검증은 별도다.

## 남은 기능 추가 검증

- RGB-D 정합 모드는 격리 설정 파일에서 유효 모드, 보존할 설정, 후보·파일 충돌, 백업·복원을 확인하고 실제 시작 설정 경로를 읽기로 검증한다. 장치 공장 외부 파라미터 변경이나 실제 재시작은 수행하지 않는다.
- 휠 다점 측정은 최신 포트 피드백·중복·부호·범위·속도 다양성 및 회귀 잔차를 검증한다. 정지 상태 시험과 보정 동작은 구분한다.
- 그리퍼 힘 기록은 외부 측정 출처·대상 물체·단위·샘플 범위를 검증하며 센서 기반 힘 제어 또는 실제 파지 시험으로 주장하지 않는다.

## 보정 깊이 소비자 연결 검증
- 합성 영상·격리 ROS에서 미정합 프레임은 포인트클라우드 발행을 거부하고, 컬러 광학 프레임은 구독자에게 전달되며 활성 보정값 변경 시 발행이 중단됨을 확인했다. 시험은 소스 노드와 구독 노드를 독립 executor에서 실행한다.
- 일치하지 않는 기준 영상·보정 해시의 선택 거부, 기준값 변경 거부 및 기본 입력 복귀를 임시 파일/API에서 확인했다. 큐브 순수 계산과 투영·배경 가드 시험 15건 및 관련 API 41건 통과.
- 실제 카메라 미정합 모드, 체커보드 촬영, 보정 결과의 물리적 정합 정확도와 부하·Nav2/충돌 모니터 종단 동작은 미검증이다. 시뮬레이션 통과를 실기 안전으로 해석하지 않는다.
