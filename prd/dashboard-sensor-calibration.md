# 대시보드 센서 보정

## 목표와 범위
운영자가 웹에서 센서 보정의 준비 상태와 측정 결과를 확인한다. 우선 카메라 컬러 영상의 체커보드 내부 파라미터 후보 정지 IMU 자이로 bias 및 여섯 자세의 가속도 오프셋·배율 후보를 다룬다. 센서값은 기존 보정이 적용될 수 있으므로 장치별 현재 상태를 확인하고 출처·단위·시각을 함께 표시한다.

## 경계
실제 로봇 동작을 명령하지 않는다. 측정 결과는 검증 전 후보이며 실제 드라이버/설정에 자동 적용하지 않는다. 카메라 내부 보정은 depth 정렬, 외부 좌표계 및 IMU 축 정렬 보정을 뜻하지 않는다. 가속도 후보는 축별 오프셋·배율만 추정하며 교차축 오차 보정이 아니다. 운영자만 측정·저장하고 조회자는 결과만 볼 수 있다. 측정 중 장치 미수신, 움직임, 중복/부족한 촬영과 시간 초과를 명확히 표시한다. 실행 중 취소는 아직 제공하지 않으며 서버 재시작 시 진행 중 측정은 중단된다.

## 구현 방향과 미확정 사항
기존 ROS 보정 도구와 영상 토픽을 재사용하고 설정 파일을 덮어쓰지 않는 별도 후보 저장소를 사용한다. IMU는 이미 적용 중인 `/base_node`의 gyro_bias를 확인해 잔차에 더한다. 카메라는 영상의 여러 위치·각도와 사용자가 지정한 체커보드 치수가 필요하다. 사용자가 카메라 내부·IMU 자이로를 범위로 확인했으며, 후보 저장 후 실제 장치 적용은 별도 작업으로 결정했다. 실물 검증 전에는 후보로 표시한다.

여섯 자세는 사용자가 안전하게 지지하며 직접 놓고 각 자세에서 정지해 측정한다. 중력 방향·발행자·시간·정지성을 검증하며 서로 다른 발행자의 측정은 합치지 않는다. 장소 변경만으로 다시 보정할 필요는 없고 센서 장착 변경·충격 또는 편차 발견 시 재확인한다. 결과는 미적용 후보이며 실제 정확도는 미검증이다.
