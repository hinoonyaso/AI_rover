# 대시보드 Gazebo 자동 준비

2026-11-17 사용자 요청: 웹 임무 실행 시 별도 터미널에서 Gazebo·Nav2·가상 경광등을 먼저 준비하는 불편을 제거한다.

임무마다 별도 Gazebo partition을 생성하고 domain 31 및 루프백 전용 UDP 설정을 사용한다. 도메인에서 기존 시뮬레이터·실제 베이스 노드를 발견하면 기동을 거부하고 기존 프로세스는 종료하지 않는다. 준비, 주행, 점검 단계를 임무 상태로 기록하고 취소·종료 시 이 임무가 만든 프로세스 그룹만 정리한다. 실제 로봇 모드는 허용하지 않는다.

검증: 격리 대시보드 API에서 사전 Gazebo 기동 없이 가상 경광등 점검 1회 성공, 준비 중 취소 1회와 주행 단계 진입 후 목표 전 취소 1회 확인, 각 시험 후 Gazebo·Nav2 잔여 프로세스 없음. 충돌 거부 단위 시험과 운영 백엔드 51건·화면 빌드 통과. 실제 목표 전송 후 취소, 장시간 반복과 예기치 못한 강제 종료 상황은 추가 검증이 필요하다.
