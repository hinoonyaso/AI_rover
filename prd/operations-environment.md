# 관제·기록·운영 개발 환경

목적: Jetson에서 재현 가능한 FastAPI·React 관제, MySQL 개발 DB, 상태·이벤트 기록 및 사용자 서비스 실행 환경을 구성한다. 초기 단계는 읽기 전용이며 모터·팔·ROS bringup 및 임무 실행 기능을 포함하지 않는다. 데이터는 사용자 디렉터리와 localhost에 둔다.

구조: 브라우저 → localhost FastAPI → 정적 React 및 상태 API → 호스트 메트릭/로컬 MySQL. 장치/ROS 토픽/임무 상태는 미연결 시 미확인으로 표시한다. MySQL에는 운영 이벤트 및 시스템 메트릭을 저장한다. DB 연결 실패 시 API는 상태와 오류를 보여주고 허위 정상 값을 내지 않는다. MySQL/서버 사용자 서비스는 계정 로그인 시 시작하며 하드웨어를 기동하지 않는다. 재부팅 후 로그인 없이 시작하려면 별도 시스템 설정이 필요하다.

기술 결정: 프로젝트 확정안에 따라 초기 MySQL, FastAPI, React를 사용한다. PostgreSQL 전환 및 별도 VectorDB는 추후 작업이다. 시스템 패키지 설치가 불가능할 경우 사용자 전용 설치/실행을 우선하며, 그마저 불가능하면 누락을 기록한다. 외부망 공개 및 인증은 범위 밖이라 127.0.0.1만 수신한다.

검증: DB 초기화·재시작 및 이벤트 보존, API 정상·DB 중단 오류, UI 빌드 및 조회, 서비스 상태, 측정 데이터 기록 확인. 장시간 시험은 별도 실제 실행·측정으로만 완료 처리한다. ROS·제어 연동과 비상정지는 미구현이다.
