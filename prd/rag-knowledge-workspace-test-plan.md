| 항목 | 수준 | 통과 기준 |
|---|---|---|
| 설계 | L0 | 기존 API·권한·운영 방식과 데이터 출처/신뢰·안전 경계 검토 |
| 수집·색인 | L0 | 임시 디렉터리에서 허용 자료만 색인; 비밀·경로 이탈 차단, 변경·삭제·실패 복구 검증 |
| 검색·답변 | L0 | 고정 한국어 질의 세트에서 출처·정답 근거와 없는 자료에 대한 거절, 프롬프트 주입 및 오류 처리 검증 |
| 권한·화면 | L0 | 미인증/조회자 쓰기 거부, 운영자 색인, 검색·상세·빈 상태·DB 장애 표시 및 프런트 빌드 |
| 시스템 통합 | L0/L2 | 격리 DB에서 API→벡터 DB→로컬 모델 연동; ROS 센서 동시 사용 시 자원·지연과 기존 관제 유지 확인, 모터와 팔 구동 없음 |
| 검색 품질 | L0 | 실제 사용자 질의 최소 30개와 정답 근거를 사전 정의; Recall@5 및 근거 없는 답변 수를 기록하고 기준은 평가셋 검토 후 확정 |
| 복구 | L0 | 색인 도중 실패·재시작 시 마지막 정상 색인 유지, 백업 복원 검증 |

## 진행 기록 (2026-11-18)
- 실제 Jetson에서 9개 지정 문서 195개 청크 색인(약 26초), 임베딩 384차원 및 로컬 Qwen 답변 단일 사례 확인. 해당 색인은 코드 개선 전 생성되었고 검색 순위는 별도로 수정했다.
- 격리 저장소의 색인·검색·심볼릭 링크 제외·실패 후 이전 색인 유지와 격리 API 미인증/조회자 쓰기 거부 시험 4건 통과. 대시보드 빌드와 기존 렌더링 시험 통과. 실제 HTTPS 서버의 미인증 API 401과 화면 200 확인.
- 라이다·카메라·IMU 질문 및 무관 질문은 표본 확인 수준이며 30개 평가셋, 실계정 로그인 종단 간, 브라우저 상호작용, 재부팅 복구, 부하 시험은 미완료. 초기 암호로는 로그인되지 않아 현재 암호 확인 없이 반복 시도하지 않았다.

- 2026-11-18 실제 HTTPS 운영자 로그인 → 색인 상태 195건/문단 목록 20건 → 라이다 검색 → 로그아웃 성공. 카메라 질문의 로컬 답변 API도 200으로 86.3초 만에 5개 근거를 반환했으나, 답변에 근거만으로 확인되지 않는 설명이 있어 정확성은 미검증이다. 브라우저 상호작용과 대표 질의 품질·동시 부하 시험은 남음.

- 2026-11-18 기본 근거 답변과 실시간 질문 차단 적용. 같은 평가셋의 출처 Hit@5 25/25, 무관/실시간 질문 거부 3/5→5/5. 기존 생성형 단일 응답 86.3초, 변경된 기본 원문 답변 3회 0.043/0.041/0.040초. 비교는 서로 다른 답변 방식임. 상세와 제약: `docs/benchmarks/rag/knowledge-evaluation-20261118.md`.

- 추가 평가: 새로 작성한 15개 질문의 엄격한 정답 문구 포함률 상위 3문단 기준 5/15. 생성형 2건 모두 근거와 다른 설명 확인(78.5초, 83.5초). 센서·카메라 실행 중 약 159초 관측에서는 상태 API 오류 0/52, 스냅샷 최대 0.50초. 동의어 미인정·단일 짧은 시험 등 한계는 `docs/benchmarks/rag/knowledge-additional-evaluation-20261118.md` 참조.

- 2026-11-18 EXAONE과 Qwen 로컬을 같은 검색 근거로 2문항 비교: EXAONE 2건은 제공 근거에 부합(카메라 59.40초, 자이로 근거 부족 유보 88.82초), 로컬 2건은 근거 밖 오류 포함(79.54/76.96초). EXAONE 최초 429 서비스 혼잡 후 카메라 재시도 성공. 작은 표본·상이한 모델 설정·동시 부하 한계는 `docs/benchmarks/rag/exaone-local-comparison-20261118.md` 참조.

- 검색 개선 후 기존 15개 문단 평가 5/15→12/15, 기존 출처 Hit@5 25/25·무관 질문 거부 5/5 유지. 변경 후 새 8개 질문 7/8. 단 문자열 판정·튜닝 사용·소규모 결과이며 생성 답변 재검증은 별도. 상세 `docs/benchmarks/rag/knowledge-search-improvement-20261118.md`.
