# 대시보드 센서 연결 검증

| 범위 | 기준 |
|---|---|
| 카메라 서비스 | 고정된 서비스만 시작/종료, 중복 외부 노드 거부, 비인가 사용자의 쓰기 거부, 수신 여부와 실행 상태 구분 |
| 센서 전용 base_node | 격리 ROS 및 가짜 시리얼에서 IMU 측정과 어떤 입력에도 모터/팔 프레임 및 e-stop 해제 프레임 미발행 검증 |
| 실기 | 로봇 구동 전 별도 안전 확인. 실제 센서 수신은 실기 결과와 구분해 기록 |

## 2026-11-17 결과
가짜 시리얼·격리 ROS 도메인에서 IMU 1001개 수신, cmd_vel 구독 0개, 시작·종료 포함 시리얼 전송 0개. 카메라/IMU 실제 센서 전용 서비스를 기동해 카메라 약 29Hz, IMU 약 50Hz와 배터리 약 12.53V 수신. 동작 중 실제 바퀴·팔 구동 시험은 수행하지 않았다. 서비스 중복 방지·고정 명령 단위 시험 통과.

2026-11-17 LiDAR 전원을 연결한 뒤 지정 by-path 포트가 유효함을 확인하고 수동 서비스로 기동했다. ROS `/scan` 약 13.6 Hz 수신.
