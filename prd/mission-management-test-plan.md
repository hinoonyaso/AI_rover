# TEST_PLAN: 임무 생성·실행·관제

신뢰 수준: 초안(2026-11-15). 레벨은 `AGENTS.md` 정의를 따른다. 실기 시험은 별도 승인과 시나리오 확정이 필요하다.

| 작업 | 레벨 | 통과 기준 |
|---|---|---|
| 상태·계약 | L0 | 허용/금지 전이, 종결 불변성, 중복 ID·유효하지 않은 인자, 모의·실제 모드와 오류 코드가 검증된다. |
| 모의 관리자·DB | L0 + L1 | 격리 DB에서 성공·실패·타임아웃·취소 경쟁, 중복 요청과 동시 실행 제한을 검증한다. 상태와 이벤트가 원자적으로 기록되고 DB 오류에서 새 실행을 거부한다. 재시작 후 활성 임무가 자동 재실행되지 않고 중단으로 기록된다. |
| 웹 관제 | L0 + L1 | 모의 생성·실행·취소와 현재 단계·이력이 API 및 UI에 일치한다. 연결 끊김·빈 이력·DB 실패·실행 거부를 구분하고 모의 표시가 유지된다. 실제 실행 기능 게이트 미충족 시 서버가 거부한다. |
| 안전·경계 | L0 + L1 | 모의 모드에서 모터·팔·ROS Action 전송이 0건이다. 취소 요청은 확인 전 완료로 표시하지 않는다. 지연/중복 응답이 종결 상태를 덮지 않는다. localhost 경계와 인증·권한 검증을 확인한다. |
| 실제 어댑터 | L1 | 사용자와 확정된 단일 시나리오에서 가짜 Action 서버 또는 시뮬레이션으로 성공·실패·타임아웃·취소, 서버 불가, 중복 결과를 검증한다. 실기와 별도 기록한다. |
| 실기 | L2~L5 별도 승인 | 센서 확인(L2) 후 바퀴 띄운 시험(L3), 별도 승인된 저속 바닥 시험(L4), 통합 임무(L5)를 순차 수행한다. 프로젝트 안전 조건과 시나리오별 정량 기준을 사전 확정한다. 기존 전체 목표 10회 중 8회 이상은 통합 시험 기준이며 미측정이다. |

테스트는 운영 DB나 실행 중인 로봇에 모의 데이터를 주입하지 않는다. 기존 데이터 백업·복구 검증은 격리 사본으로 한다. 물리 시험 실패나 미실행은 별도 남기며 전체 실기 완료로 표시하지 않는다.
