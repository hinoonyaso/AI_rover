# PRD: Gazebo 동적 장애물 대응 (반응형: 멈추고 기다리기)

- 작성: 2026-10-21. 신뢰 수준: **계획**. 사용자 승인 2026-10-21(제안 수치 그대로: 대기 상한 5 s, 간격 ≥ 10 cm, 재출발 ≤ 2 s).
- 사용자 결정(2026-10-21): 대상 = 사람(걷는 다리), 갑자기 나타나는 정지 물체, 낮은 물체(굴러오는 상자 등) / 범위 = **1단계 반응형만**(예측·추적은 부족할 때 다음 단계) /
  충돌 위험 시 동작 = **멈추고 지나가길 기다림** / 검증 = **sim 먼저, 실기는 나중**.
- 관련: `prd/sim-avoidance-precision.md`(정지 상자 회피, 최종 설정 `tools/nav/ab_params/nav2_params_sim_avoid.yaml`),
  `docs/benchmarks/sim/avoidance_precision_20261020.md`, troubleshooting/050·052.

## 목표
정지 상자 회피(8.15)는 sim에서 목표를 달성했지만 **정지 장애물만** 검증했다. 로봇이 다니는 실내에는 사람이 지나가고, 주행 중에 물건이 경로에 놓이며,
LiDAR에 안 잡히는 낮은 물체가 굴러올 수 있다. 이번 목표는 이런 상황에서 **부딪히지 않고, 멈춰서 기다렸다가 지나가면 다시 가서 목표에 도착**하는 것이다.
- 움직이는 장애물(사람·굴러오는 상자): 경로 가까이 오면 멈추고, 지나간 뒤 다시 출발한다. 그 사이 억지로 비켜 가지 않는다.
- 갑자기 나타난 정지 물체: 일단 멈추고 잠시 기다린 뒤, 계속 그 자리에 있으면 정지 장애물로 보고 기존 방식(옆이동 회피)으로 돌아간다.

## 범위
- **장애물 표현**: depth 지우기 켬(8.15 최종 설정)으로 지나간 자리의 잔상을 지운다. LiDAR 레이어 지우기 확인. 부족하면 높이를 구분하는 VoxelLayer를 후보로 시험.
- **정지 판단(반응형)**: 예측 없이 지금 보이는 장애물로 판단한다. 후보(가설별로 시험):
  - collision_monitor `approach`(현재 명령 속도로 t초 안에 닿으면 정지) — 이전에 정지 상자 옆 정상 회피까지 막아 껐던 방식이라, 시간·영역을 줄여 재검토
  - collision_monitor 정지 영역 + BT 대기·재시도 시간 조정
  - DWB 자체 회피와 "멈추고 기다림"이 충돌하지 않게 하는 설정(움직이는 것을 굳이 돌아가려 하지 않게)
- **기다림 → 재출발 → 필요 시 회피**: 대기 시간 상한 5 s(승인)을 넘어도 막혀 있으면 정지 장애물로 보고 재계획.
- **Gazebo 동적 장애물**: 시험용 움직이는 모델과 구동 노드
  - 사람: 다리 두 개(원기둥, LiDAR 높이에 걸림) + 몸통, 일정 속도로 경로 이동
  - 낮은 상자: 33×22×11 cm 상자(LiDAR에 안 보임)를 경로를 가로질러 이동
  - 갑자기 나타나는 상자: 로봇이 지점을 지나면 앞쪽 경로에 순간이동
  - 구동은 정답 위치를 아는 순간이동 반복(kinematic) 방식(추정: 가장 단순, 접촉은 정답 기하로 판정)
- **측정**: 기존 시험 도구(`avoid_trials.py`, `avoid_metrics.py`)를 확장해 움직이는 장애물과의 최소 간격, 정지 반응 거리, 재출발 지연, 대기 시간, 접촉 여부, 도착 성공·오차·시간을 잰다.
- **회귀**: 정지 상자 S1/S2/S4가 기존 목표를 계속 만족하는지 확인한다.

## 비범위 (지금은 안 하는 것)
- 장애물 추적·속도 추정·예측(칼만 필터, 예측 위치를 코스트맵에 칠하기) — 1단계로 부족할 때 2단계 PRD
- 사람 인식(YOLO)·사람 전용 동작(사회적 거리 등)
- 로봇보다 빠르게 로봇을 향해 달려오는 장애물(멈춰도 피할 수 없음 — 안전망 정지만 확인)
- 뒤쪽·옆쪽에서 오는 낮은 물체(깊이 카메라는 정면만 봄, 후진 금지 유지)
- 실기 시험(이번 범위는 sim. 실기는 승인된 설정으로 나중에 따로)
- 실기 공식 설정 변경(sim 변형으로만)

## 제약
- AGENTS.md 안전 규칙과 확정된 사실. 후진 금지(`min_vel_x 0`), 최고 속도(0.12 m/s 근처) 유지.
- 파라미터 변경마다 설정 주석(이전 → 새 값, 날짜, 이유)과 `docs/benchmarks/navigation/tuning-history.md` 한 줄. 되돌린 값도 적는다.
- collision_monitor 정지 영역(몸 + 2 cm)은 줄이지 않는다(마지막 안전망).
- 정지 상자 회피(8.15) 결과가 나빠지면 안 된다.
- 깊이 카메라는 정면 약 83°, 0.2~3 m만 본다. 낮은 물체는 정면에서만 감지된다.

## 완료 기준 (sim, 2026-10-21 승인)
- 동적 시나리오 각 10회: 접촉 0, 움직이는 장애물과 최소 간격 ≥ 10 cm, 목표 도착(오차 ≤ 5 cm) ≥ 9/10,
  장애물이 경로에서 벗어난 뒤 재출발 ≤ 2 s, 갑자기 나타난 정지 물체는 대기 상한 뒤 회피해 도착
- 정지 상자 S1/S2/S4 회귀: 기존 기준 ≥ 9/10 유지
- 문서: 결과 벤치마크, troubleshooting, tuning-history, 체크리스트
