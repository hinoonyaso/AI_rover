# PRD: Gazebo 회피 주행 정밀도 향상 (메카넘 회피 + 정밀 도착)

- 작성: 2026-10-18. 신뢰 수준: **계획**. 사용자 승인 범위: 도착 정확도와 깔끔한 회피를 모두, 메카넘 장점(옆이동)을 쓰는 회피, 정밀 접근 노드 추가 허용, 아래 목표 수치.
- 관련: `prd/gazebo-sim.md`(시뮬레이션 기반), `docs/benchmarks/navigation/dwb_vs_mppi_20261011.md`(실기 B 결과), `tools/sim/README.md`(S1~S3), `troubleshooting/028`·`031`.

## 목표
실기 상자 우회(B)는 DWB·MPPI 모두 성공 1/5였다(2026-10-11).
- DWB: 위치 오차 13.5 cm, 우회 폭 39 cm
- MPPI: 상자 앞에서 10~20 s 망설이고, 회전→직진→회전으로 돌아감(메카넘 옆이동을 못 씀)
- 원인 후보: 전역 경로가 상자 좌우로 뒤집힘(미확인), 허용 오차 10 cm 안에서 멈추는 구조

실기 배터리·시간을 쓰지 않고, **정답 위치를 아는 Gazebo**에서 원인을 하나씩 확인하고 고친 뒤 실기로 옮긴다. 두 가지를 모두 달성한다.
1. **회피 동작**: 상자 앞에서 망설이지 않고, 몸은 진행 방향을 보면서 옆이동(vy)으로 짧게 돌아간다.
2. **도착 정확도**: 목표에 5 cm 이내로 도착한다. Nav2로 근처까지 간 뒤 메카넘 정밀 접근으로 마지막 거리를 맞춘다.

## 범위
- 시뮬레이션 준비: 월드는 `room_lap2_objects.sdf`(스캔한 방 + Nav 상자 33×22×11 cm `object_0`, 사용자 지정), 시뮬레이션용 깊이 기준 영상(`depth_obstacles:=true`)
  - 상자 높이 11 cm는 LiDAR(약 15 cm)에 안 보인다.
- 시나리오: S1 직진(회귀 확인), S2 상자 옆 치우침(실기 F2/B 대응, 상자 모서리가 경로선 4.5 cm 오른쪽), **S4 상자 정면**(경로선 한가운데, 새로 추가)
- 측정: Gazebo 정답 위치(gz 모델 자세)로 다음을 잰다. 회차 자동 반복과 요약 표를 만든다.
  - 도착 위치·방향 오차
  - 상자와의 최소 간격(정답 기하)
  - 우회 폭, 시간
  - 망설임(vy 부호 반전/초, 정지 시간)
  - 몸 방향 이탈(회피 중 경로 방향 대비)
  - 전역 경로 좌우 뒤집힘 횟수
- 원인별 단일 변수 실험: 깊이 장애물 유지, 전역 경로 뒤집힘, 메카넘 옆이동 회피(RotationShim/DWB/MPPI 설정), MPPI 망설임
- 정밀 접근 노드: Nav2 성공 후 목표 근처(≤ 15 cm)에서 저속 전방향 P 제어로 위치·방향을 맞춘다. 속도 제한, 시간 제한, 거리 제한, collision monitor 경유.
- 실기 검증: 최종 설정으로 실기 B 5회

## 비범위 (지금은 안 하는 것)
- 컨트롤러를 상황별로 바꾸는 BT(9단계 Navigation BT), AprilTag 정밀 정렬
- 다른 장애물 모양·여러 장애물, 움직이는 장애물
- 로봇 뒤쪽 센서(후진 금지 유지)
- 새 2D 지도·낮은 벽(8.14.7의 별도 항목)
- 실기 지도·AMCL 파라미터 재튜닝(필요가 드러나면 별도 항목으로)

## 제약
- AGENTS.md 안전 규칙: 실기 시험은 0.12 m/s 이하, 사용자 입회, 배터리 충전. 후진 금지(`min_vel_x 0`) 유지.
- 파라미터 변경마다 설정 파일 주석(이전 → 새 값, 날짜, 이유)과 `docs/benchmarks/navigation/tuning-history.md` 한 줄. 되돌린 값도 적는다.
- 한 번에 변수 하나. baseline 측정 중에는 설정을 바꾸지 않는다.
- 시뮬레이션 결과는 "시뮬레이션 증거"로 표시한다. 실기 판단은 실기 시험으로만 한다.
- 정밀 접근은 AMCL 위치를 믿고 움직이므로, 도착 정확도의 하한은 위치 추정 정확도다. 시뮬레이션에서 AMCL 오차를 정답과 비교해 따로 기록한다.
- host 실행: `ROS_DOMAIN_ID=31`, `GZ_IP=127.0.0.1`. 로봇(25)과 분리한다.

## 완료 기준
- 시뮬레이션(S2·S4 각 10회, 최종 설정):
  - 성공 ≥ 9/10
  - 도착 위치 오차 ≤ 5 cm(정밀 접근 포함, 정답 기준)
  - 상자와 최소 간격 ≥ 5 cm
  - 전역 경로 뒤집힘 0회
  - 25 s 이내
  - 회피 중 몸 방향 이탈 ≤ 20°(옆이동 회피)
- S1 회귀: 성공률·시간이 baseline보다 나빠지지 않는다.
- 실기 B 5회: 성공 ≥ 4/5, 충돌 0
- 설정·도구·시험 결과 문서화(`docs/benchmarks/sim/`, `tuning-history.md`, 체크리스트)
- 정밀 접근 노드: 단위시험 통과(속도·거리·시간 제한, 목표 도달 판정), `colcon test` 통과

## 진행 메모 (2026-10-20)
- 시나리오 좌표를 스캔 방 기준으로 조정했다(B (1.00, 1.25), 상자 S2 (1.21, 0.78)/S4 (1.00, 0.78)). sim 시험은 AMCL 대신 정답 위치로 초기화한다(스캔 월드 자동 위치 추정 오차, troubleshooting/046). 실기 도착 정확도는 AMCL(3~8 cm)이 한계다.
- 결과: `docs/benchmarks/sim/avoidance_precision_20261020.md`. 성공·도착 오차는 목표 달성, 상자 간격은 평균 5.3~6.2 cm(시행별 최소 2.6~3.5 cm). 실기 검증은 남았다.
