# TEST PLAN: 음원 방향 인식

| 항목 | 수준 | 기준 |
|---|---|---|
| 장치 입력 확인 | L0/L2 읽기 | ALSA 원시 채널 수·샘플레이트, 시리얼 장치 식별 및 확인 응답 기록. 위조 채널·근거 없는 포트 추정 금지. |
| 프레임·파서 | L0 | 분할·연속·잘못된 체크섬·과대 길이·무효 JSON/각도를 거부하고 확인 메시지는 ID와 체크섬이 맞음. 합성 메시지는 실기 증거 아님. |
| 깨우기 이벤트 | L2 읽기 및 확인 응답 | 실제 이벤트가 반복 수신되고 정확한 메시지 구조와 유효 각도가 확인됨. 녹음 내용/키워드는 기본 저장하지 않음. 현재 미통과. |
| 방향 보정 | L2 | 로봇 정면·좌·우·후방에서 각각 여러 번, 기준 방향·거리·오차·실패율을 기록하고 좌표계/증가 방향을 확인. 측정 전 변환 금지. |
| 연속 DOA | L0 + 실제 음원 | 합성 방향·무음·입력 오류 및 8채널 WAV 매핑 테스트 통과. 실제 6채널 동기 데이터 또는 검증된 연속 방향 API를 확보한 후 여러 소리/정면·좌·우·후방과 재현율·지연·정확도를 평가한다. 실기 미확인. |

실기 음원 위치 확인은 사용자 입회로 하며 로봇 모터 구동은 포함하지 않는다. 평가 수치는 측정 환경을 합의·기록하고 확정한다.
