# 접촉 파지 속도: 빠른 접근 (2026-10-15)

목적: 닫기 19~21 s(제한 30 s에 여유 10 s, `arm_grasp_l2_20261014.md`)를 줄인다. 변경: `GraspStateMachine`에 빠른 접근 —
접촉 창 아래 `contact_lo - 40 = 465` 펄스까지 0.8 s에 한 번 이동한 뒤 기존 정밀 스텝(12펄스, 250 ms + 정착 0.2 s, 접촉 재확인).
접근 중 0.3 s 동안 2펄스 미만 진행이면 막힌 것(이 프로파일보다 큰 물체)으로 보고 `OutsideWindow` 실패·시작 위치로 다시 연다.
파라미터 `grasp_approach_margin/approach_ms/stall_s`(base.yaml 40 / 800 / 0.3, 코드 기본은 꺼짐), 정밀 스텝 값은 그대로(T3 검증값).
원자료 `docs/benchmarks/arm_grasp_speed_20261015/*.json`(도구 `grasp_l2_run.py --dwell-s 3`).

## L2 실기 결과
| 구분 | 회차 | 결과 | 소요(goal → 결과, 조임·2 s 유지 확인 포함) | 접촉 |
|---|---|---|---|---|
| 큐브 | 11 유효 | **10 성공**, 1 `HoldNotStable` | 성공 7.7~10.0 s, **중앙값 7.8 s**(이전 19.2~20.7 s) | 520~535(이전 525~534, 창 [505, 545]) |
| 빈 그리퍼 | 2 | 2 `NoContact`, 다시 열림 | 12.7 s(이전 23.1 s) | — |

- 유지 변동(조임 뒤 3 s 관찰) 1~3 펄스, 그리퍼 온도 39~48 ℃.
- `HoldNotStable` 1회(5회차, 접촉 530): 조임 후 2 s 확인에서 ±3을 넘음. 접근 단계와 무관한 단계이고 이전 실기에서도 유지 변동 4가 한 번 있었다 →
  `hold_tol` 3이 실기 흔들림 경계에 있다(임시값 확정 때 볼 것).
- 제외: 첫 묶음 6~10회차 5회 `BadStart` — `HoldNotStable`은 정책대로 접촉 위치까지만 풀어 그리퍼가 닫힌 채였고, 도구가 회차 사이에 열지 않았다
  (시험 도구 문제). `grasp_l2_run.py`에 회차 전 자동 열기를 넣은 뒤 6회 6/6.
- **실기 미실시**: 3 cm보다 큰 물체(빠른 접근 중 막힘) — 4~5 cm 물체가 없어서. 증거는 L0·L1뿐.

## 남은 것
- 정밀 스텝(250 ms / 0.2 s)은 그대로 — 더 줄이면 1~2 s 더 빨라질 수 있으나 접촉 검출 검증이 다시 필요.
- 첫 닫기 명령이 두 번 나가는 동작(접근 이전부터 있던 것, 같은 목표 재전송이라 무해)은 그대로.
- `cube3cm` 임시값 확정(창, 조임 +16, `hold_tol` 3, 제한 30 s → 이제 닫기 약 8 s라 줄일 수 있음).
