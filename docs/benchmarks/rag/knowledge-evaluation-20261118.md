# 지식 검색 품질 평가 — 2026-11-18

## 조건
Jetson Orin Nano 8GB, 기존 운영 대시보드 HTTPS API, FastEmbed 다국어 MiniLM 양자화 모델, Qdrant 로컬 모드, 9개 문서 195개 청크. 동일한 수동 작성 질문·출처 정답 30개를 변경 전후 1회씩 실행했다. 평가셋: `tools/ops/evaluation/knowledge_cases.json`, 실행 도구: `tools/ops/evaluation/evaluate_knowledge.py`. 정답 출처는 각 문서를 살펴 사람이 지정했다. 결과 파일은 각각 `knowledge-baseline-20261118.json`, `knowledge-after-20261118.json`이다. 데이터는 학습·튜닝과 독립된 블라인드 집합이 아니다.

## 측정 결과
| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 출처 Hit@5 (질문당 정답 출처 하나 이상) | 25/25 | 25/25 |
| 무관·실시간 질문에서 검색 결과 없음 | 3/5 | 5/5 |
| 30건 검색 응답 중앙값 | 64.5ms | 51.5ms |

Hit@5는 관련 파일이 하나라도 반환됐는지 측정하며, 문단 자체가 답을 포함하거나 1위라는 뜻은 아니다. 5개 거부 질문 중 2개는 실시간 배터리·위치 질문이다. 고정 키워드 기반 분류이므로 다른 표현의 실시간 질문에 대한 보장은 없다. 비실시간 질문과 실시간 상태 질문이 함께 들어간 경우 문서 검색을 보수적으로 유보할 수 있다. 표본이 작으며 사용자 질의에 대한 일반화 성능은 추가 평가가 필요하다.

## 답변 방식 및 지연
변경 전 카메라 질문의 Qwen 1.7B 생성 응답 1회는 86.3초였고, 출처에 없는 추론을 사실처럼 덧붙인 내용이 있었다. 기본 동작을 생성형 요약에서 검색된 문단을 그대로 표시하는 근거 답변으로 변경한 뒤 동일 질문의 실제 HTTPS 요청 3회는 각각 0.043, 0.041, 0.040초였다. 서로 다른 답변 방식과 각각 1회/3회 표본이므로 동일한 생성 모델을 2,000배 가속한 수치가 아니다. 인용 문단이 원문과 일치함을 확인했지만 문단이 질문의 정답을 담는지 자동으로 보장하지 않는다. 생성형 답변은 별도 선택이며 그 정확도와 응답 시간은 개선됐다고 주장할 수 없다.

## 검증 및 미완료
격리 지식 API, 기존 인증, 실시간 질문 거부 및 원문 표시 테스트 6건 통과. 프런트 빌드 및 실제 HTTPS 로그인→검색→기본 답변 확인. ROS와 동시 사용한 장시간 부하, 사용자 브라우저 수동 검증, 독립적인 질의셋에서 문단 수준 정답률 및 생성형 답변의 사실성 평가는 수행하지 않았다.
