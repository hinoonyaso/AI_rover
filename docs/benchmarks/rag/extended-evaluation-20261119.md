# 추가 RAG 평가와 10분 생성 부하 시험 (2026-11-19)

## 검색과 유보
사용자가 요청한 범위에서 복원한 195청크 색인을 이용해 새로운 질문을 작성했다. 질문 작성자는 프로젝트와 기존 평가를 알고 있으며 블라인드 데이터가 아니다. 답변에 필요한 지정 출처·문구가 상위 3개 검색 결과에 있으면 근거 적중으로 집계했다. 문자열 자동 채점은 동의어 표현을 놓칠 수 있다. 세대별 색인과 문서가 바뀌면 결과가 달라질 수 있다.

- 추가 26개 질문(문서 근거 18, 무관·실시간 8): 초기 **13/18**, 유보 **6/8**. 실시간 이동 질의를 문서에서 추측하고 미색인 바코드 프린터에 무관 문서를 반환했다. 이동·주행과 시간 표현을 함께 묻는 질의를 실시간으로 분류하고, 검색 결과 전체에 질의 원문 단어나 알려진 장치 별칭이 하나도 일치하지 않으면 보수적으로 유보한 뒤 **13/18, 8/8**이었다. 해당 질문은 수정에 사용됐으므로 독립 사후 성능은 아니다.
- 자연스러운 바꿔 묻기와 미색인 장비 18개(근거 10, 무관 8)는 변경 전 **7/10, 5/8**, 변경 후 **7/10, 6/8**이었다. 제빙기·피자 도우 질문은 여전히 무관한 문서가 반환됐다. 단어 일치가 없으면 유보하는 규칙은 동의어 질의를 과도하게 유보할 수 있고, 일치가 있어도 정답 근거임을 보장하지 않는다. 이 집합도 규칙 검토에 활용됐다.
- 이후 작성한 18개 별도 질문(근거 12, 무관 6)에서 **9/12, 4/6**을 기록했다. 현재 충전량 질문을 보고 실시간 키워드를 보완해 해당 문항의 수정 후 결과는 **9/12, 5/6**이며 이 집합도 개발에 사용된 것으로 본다.
- 최종 수정 후 별도 작성한 16개(근거 10, 무관 6)는 **8/10, 5/6**이었다. 미색인 의류 건조기 질문에 무관한 자료가 반환됐다. 이 수치는 추가 규칙 조정에는 사용하지 않았지만 같은 사람이 작성한 소규모 평가라 일반화할 수 없다. 입력·근거·상세 결과: `tools/ops/evaluation/knowledge_final_diverse_20261119.json`, `final-diverse-search-20261119.json`.

## 생성 답변 확대 평가
기존 생성 평가에 더해 EXAONE에 실제 검색 문단이 있는 4개 질문을 전달했다. (1) 포트 번호의 문서 근거가 선택되지 않은 질문은 근거 부족으로 유보, (2) 보정 후보 저장 권한은 운영자라고 근거와 일치, (3) 가상 경광등 질문은 HTTP 호출은 진행됐으나 내용 없는 답변으로 실패, (4) 제빙기 질문에는 무관한 문단이 검색됐지만 모델은 근거가 없다며 유보했다. 추가로 실시간 이동·바코드 프린터 질문은 검색 단계에서 거부되어 외부 전송하지 않았다. 각각 1회이며 오류율 추정이 아니다. 원문 응답·출처는 `wider-exaone-evaluation-20261119.json`. 이전 로컬 모델 답변 평가 및 동시 비교는 `rerank-evaluation-20261119.md` 참조. 로컬 모델은 일관된 사실성이나 출처 일치가 검증되지 않았고 기본 모드는 원문이다.

## 실제 센서·서비스와 10분 로컬 생성
대시보드·DB·센서가 작동하는 정지 상태에서 복원 색인으로 준비한 두 질문의 동일한 근거를 교대로 사용해 기존 로컬 Qwen 생성 경로를 반복했다. 로봇 바퀴·팔 구동은 없었다. 생성 중 별도 검색 평가와 EXAONE 호출이 병행됐다. 요청된 600초 중 실제 **601.7초**, 성공적으로 완료된 로컬 생성 **3회**, 네 번째는 시험 시간 종료 시 중단됐다. 이 중단을 성공이나 자발적 모델 실패로 계산하지 않는다. 시작 전 메모리 3GiB 이상, 시험 중 1.25GiB 미만 또는 배터리 10V 미만이면 중단하도록 했다.

298개 센서 표본에서 ROS 스냅샷 오류·8초 이상 지연 0, IMU/LiDAR/카메라/깊이 장애물의 10초 이상 미수신 0. DB `SELECT 1` 60/60 및 인증서 검증 HTTPS 정적 페이지 60/60 성공. 인증된 대시보드 API 반복 시험은 아니며 검색·문서와 답변의 사실성도 이 부하 시험으로 보증하지 않는다. CPU 최대 81.7%, 여유 메모리 최소 1.665GiB, 스왑 최대 1.299GiB, 배터리 최소 12.484V였다. 수신율 중앙값은 IMU 49.5Hz, LiDAR 13.9Hz, 카메라 23.3Hz, 깊이 장애물 7.1Hz였다. 이전 별도 60초 생성 종료 후 카메라 중앙값 29.1Hz와 비교하면 낮았지만 두 시험은 시점과 부하가 달라 인과관계·재현성은 추가 확인이 필요하다. 데이터: `generation-stability-10min-20261119.json`.

시험 도구: `tools/ops/evaluation/prepare_generation_stability.py`, `tools/ops/evaluation/evaluate_generation_stability.py`. 결과는 부하 관찰이며 주행 중 안전성, 수 시간 이상의 안정성 또는 외부 API 가용성을 의미하지 않는다.

추가 경계 검증으로 영어 `current ... lidar` 및 `battery voltage now`도 실시간 상태 질의로 유보하도록 구현하고 단위 테스트를 통과했다. 영어 표현 전체를 처리한다는 뜻은 아니다.
