# 지식 검색 개선 및 평가 — 2026-11-18

## 확인한 원인과 변경
이전 문단 평가에서 10건 미일치 중 8건은 관련 문서가 상위 3개에 있었으나 선택된 문단이 핵심 근거를 담지 않았다. 400자 고정 분할과 문서당 한 문단만 반환하는 방식 때문에 경계 앞뒤의 내용이 누락됐다. 일부는 한국어 조사·어미 차이로 문서가 상위 결과에 없었다.

의미 벡터 점수와 문자 2-gram 부분 일치를 함께 순위에 반영한다. 검색 결과는 같은 색인 세대와 원본 SHA-256, 동일 문서의 직전·다음 청크를 추가해 문맥을 제공한다. 현재 원본 파일을 다시 읽지 않으므로 색인 이후 수정된 내용을 몰래 표시하지 않는다. 기존 색인 형식·벡터 모델은 유지했다. 부분 일치는 완전한 한국어 형태소 분석이나 의미 이해가 아니다.

## 실제 서버 평가
Jetson Orin Nano 8GB, 기존 9개 문서/195개 청크의 동일한 운영 색인과 기존 다국어 모델을 사용했다. 점수는 상위 3문단에 지정 출처와 사전 지정 문자열 중 하나가 포함되는지의 엄격한 자동 판정이다. 각 질문당 1회이며 동의어와 동일 의미의 다른 문구는 오답일 수 있다.

| 평가 | 변경 전 | 변경 후 |
|---|---:|---:|
| 기존 문단 평가 (15개) | 5/15 | 12/15 |
| 기존 출처 Hit@5 (25개) | 25/25 | 25/25 |
| 기존 무관·실시간 질문 거부 (5개) | 5/5 | 5/5 |
| 조정에 사용하지 않은 추가 질문 (8개) | 미측정 | 7/8 |

추가 질문은 변경 후 작성했으나 작성자가 프로젝트와 구현을 알고 있어 외부 블라인드 시험이 아니다. 기존 15개 질문은 개선 중 검토하여 튜닝에 영향을 주었으므로 12/15를 일반화 성능으로 볼 수 없다. 실패 항목과 출처/중심 오프셋은 JSON에 저장했다. 기존 30개 검색 요청의 변경 후 중앙값은 56ms(변경 전 기록 51.5ms)이며 부하가 통제되지 않은 각 1회 표본이다.

평가셋은 `tools/ops/evaluation/knowledge_passage_cases.json`, `knowledge_holdout_cases.json`, `knowledge_cases.json`, 실행기는 `evaluate_passages.py`, `evaluate_knowledge.py`다. 문단 결과는 `knowledge-passages-improved-20261118.json`, 추가 질문 결과는 `knowledge-holdout-20261118.json`, 출처 및 거부 결과는 `knowledge-search-improved-20261118.json`이다. 오프셋은 중심 청크 기준이다.

## 남은 한계
생성형 로컬/EXAONE 답변의 사실성은 이번 변경 후 재시험하지 않았다. 실시간 질문 감지는 정해진 단어 기반이며 일부 다른 표현과 혼합 질문에 실패할 수 있다. 더 큰 문서 집합, 다중 사용자, 장시간 부하 및 보안 관점의 허위 문서 주입에 대한 별도 시험은 필요하다.
