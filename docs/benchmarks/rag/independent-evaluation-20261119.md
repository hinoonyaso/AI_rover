# 독립 질문·색인 복원·생성 답변 평가 (2026-11-19)

## 방법과 한계
기존 검색 튜닝 질문과 표현이 다른 17개 질문을 원문 근거를 확인해 작성했다. 12개는 정답 문서와 핵심 표현을, 5개는 무관하거나 실시간이라 문서 검색을 유보해야 할 질문을 지정했다. 작성자는 프로젝트 구현을 알고 있으며 외부 블라인드 평가는 아니다. 초기 결과 확인 후 일부 정답 표현이 대안 문구인데 모두 있어야 하는 것처럼 지정된 것을 수정하고 같은 기준으로 다시 채점했다. 따라서 완전히 사전 고정된 블라인드 시험은 아니다. 기본 근거 답변에 포함되는 상위 3개 문단 중 정답 문서와 지정 표현이 함께 있는지 확인했다. 모델의 생성 답변 정확도와는 별도다.

활성 Qdrant 색인 195개 청크를 사용자 전용 파일로 논리 백업하고 별도 임시 디렉터리에 복원했다. 생성 ID·청크 수와 17개 질문의 출처·오프셋·문서 해시가 원본과 복원본에서 모두 같았다. 백업 무결성 해시 불일치와 기존 경로 덮어쓰기 거부를 격리 테스트했다. 해시는 우발적 손상 감지용이지 출처 인증이나 서명이 아니다.

## 동일 근거 생성 모델 비교
각 질문의 상위 세 문단을 한 번 확보해 로컬 Qwen3 1.7B Q4와 EXAONE K-EXAONE 2.5에 같은 질문·문맥·시스템 지시로 각각 한 번씩 전달했다. 로컬은 2스레드, 256토큰, temperature 0.1; EXAONE은 최대 1024토큰(추론 포함), temperature 1.0, reasoning low. 실행 시점과 설정이 달라 순수 모델 성능이나 일반적인 속도의 공정한 비교는 아니다. 문서와 질문은 EXAONE 외부로 전송됐다.

| 질문 | 로컬 Qwen | EXAONE |
|---|---|---|
| Orbbec SDK v2 인식과 USB 권한 | 108.10초. 두 문제가 같고 권한 규칙 부재가 원인이라고 잘못 답변, 출력이 미완결 | 28.13초. 인식 오류와 권한 자료의 관계를 신중하게 설명하며 추가 근거 부족을 유보 |
| 기존 자이로 bias 반영 | 102.07초. 잔차를 더한다는 핵심 근거 대신 후보 저장소에 관한 다른 설명 | 37.44초. 기존 bias에 잔차를 더하며 자동 적용하지 않는다고 제공 문단을 인용 |

무관 질문은 검색 단계에서 근거가 없어 두 모델 모두 호출하지 않았다. EXAONE 요청에는 앞서 429 두 차례가 있었고 재시도에서 성공했다. 성공 응답 토큰은 각각 1,598·1,804개이고 실제 비용은 확인하지 않았다. 로컬 모델은 메모리 3GiB 안전 기준을 충족하기 위해 진행 중 임무가 없는 상태에서 대시보드를 일시 중단해 실행했고 종료 후 HTTPS를 복구했다. 실시간 센서와의 생성 동시 부하·장시간 생성 안정성은 검증하지 않았다.

EXAONE은 운영자가 버튼을 눌러 매번 외부 전송을 확인했을 때만 선택 가능하다. 기본은 기존 원문 근거 답변이다. 두 사례로 정확도를 보장할 수 없으며 결과는 로봇 제어나 안전 판단에 사용하지 않는다. 실제 외부 API까지 격리 인증 경로로 통합 호출해 HTTP 200, 근거 3개, 답변 생성 및 완료 상태를 확인했다.
