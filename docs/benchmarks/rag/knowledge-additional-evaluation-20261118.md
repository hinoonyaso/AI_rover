# RAG 추가 평가 — 2026-11-18

## 조건과 범위
Jetson Orin Nano 8GB에서 운영 대시보드의 HTTPS API를 사용했다. 컬러 카메라 노드, cube_detector, ROS 모니터, sensor_only base_node가 실행 중이었다. 로봇에 구동 명령은 보내지 않았다. 기존 30개 평가 문장과 다른 문장으로 15개를 작성하고, 문서에 실제 존재하는 출처와 특정 정답 문구를 사전에 지정했다. 독립적인 외부 평가자는 참여하지 않았고 질문 설계자가 프로젝트와 구현을 알고 있으므로 블라인드 평가가 아니다.

## 문단 수준
기본 근거 답변에 들어가는 상위 3개 문단 중 정해진 출처와 문구를 모두 포함한 경우는 **5/15**였다. 미일치 10건 중 8건은 기대한 문서 자체는 상위 3개에 있었다. 출처만 찾는 이전 지표와 달리 답변에 필요한 문단 선택이 부족한 사례를 보여 준다. 사전에 정한 문자열 기반의 엄격한 판정이라 동의어·다른 위치의 동등한 답은 오답으로 처리할 수 있다. 실제로 가상 경광등 질문의 문단에는 기대 문구 대신 '가상 시험판 전용'이 있어 의미상 관련되지만 자동 판정은 실패했다. 따라서 5/15는 엄격한 기준의 결과이며 전문가가 채점한 정답률이 아니다.

재현 데이터는 `tools/ops/evaluation/knowledge_passage_cases.json`, `tools/ops/evaluation/evaluate_passages.py`, 응답 출처·위치 결과는 `knowledge-passages-20261118.json`이다. 문서 원문 대신 원문 오프셋을 보관했다.

## 생성형 답변 사실성
Qwen3 1.7B Q4 로컬 생성형 모드로 2건을 한 번씩 실행했다. 두 요청 모두 HTTP 200이었지만 답변의 정확성을 수동으로 문서와 비교한 결과 **두 건 모두 신뢰할 수 없었다**.

- 카메라: 78.5초. 문서에서 USB 권한(udev) 문제와 SDK v2의 시리얼 없는 장치 스캔 실패는 별개라고 설명하는데, 답변은 udev 규칙 미적용 가능성을 카메라 미인식 원인으로 제시했다. 스캔 실패 설명도 불충분했다.
- 자이로: 83.5초. 문서에는 기존 `gyro_bias`에 측정 잔차를 더한다고 되어 있지만, 답변은 정지 상태에서 보정이 실행되지 않는다고 주장하는 등 근거와 맞지 않는 내용을 포함했다. 검색된 상위 3개 출처에도 해당 계산 문구가 없었다.

두 사례는 생성형 답변이 근거에 없는 내용을 추가하거나 잘못 말할 수 있음을 보여 준다. 2건으로 전체 오류율을 추정할 수 없다. 모델/검색 개선 및 독립 사실성 평가 전까지 생성형 답변을 신뢰 가능한 작업 지시로 사용하면 안 된다. 기본 모드는 원문 제시이며 이 또한 적절한 문단을 찾았는지 확인이 필요하다.
