# 그리퍼 접촉 감지 검증 (T3, 2026-10-11)

PRD `prd/arm-control-path.md` R3, TEST_PLAN T3. 감지 로직: `tools/stm32_diagnostics/grasp_contact.py`(순수 모듈, 시뮬레이션 단위시험 8개 + 2700회 모의 닫기에서 접촉 위치 오차 최대 3 펄스, 가짜 접촉 0), 실기 모드 `rrc_m4_io_test.py contact-validate`. 원자료: `docs/benchmarks/arm_contact_20261011/*.json`.
**서보는 힘을 알려 주지 않는다** — 감지는 "명령을 위치가 따라오지 못함"뿐이다(12 펄스씩 닫으며 지연 > 8, 같은 명령을 다시 보내도 움직이지 않음). 그래서 감지 결과(`contact`)와 "그게 큐브인가"(`classify`, 접촉 위치 창)를 따로 판정한다.
조건: 팔 관절은 건드리지 않음(토크 그대로), 3×3×3 cm 큐브, 닫기 단계 250 ms, 조임 +16(손가락 시험은 0), 서보 온도 80 ℃ 미만(최고 그리퍼 62 ℃), 로봇 정지, 노드 모두 내림(시리얼 직접).

## 해석 (확정과 추정을 구분)
- **큐브 감지는 반복적이다**: 15회 모두 같은 범위(520~532)에서 감지, 표준편차 3.4 펄스는 서보 데드밴드(3~4)와 같은 크기. 큐브를 놓는 위치를 일부러 바꾼 시험은 하지 않았다(사용자가 놓은 대로) — 위치 의존성은 **미검증**.
- **빈 닫기에서 큐브로 오판하지 않는다**(5/5). 첫 실행은 큐브가 끼어 있어서 감지됐던 것이고(사용자 확인), 라벨을 바로잡아 큐브 기록으로 옮겼다.
- **큐브가 아닌 것의 구분은 창에 의존한다**: 손가락 접촉 438~486은 창(495~555) 밖이지만 486·481은 창 아래 끝에서 10~15 펄스뿐이다. 손가락이 더 두꺼우면(또는 큐브가 더 작은 물체라면) 창 안에 들어올 수 있다. **위치 창만으로 큐브를 보증할 수 없다**는 PRD D6의 가정이 시험으로 확인됐다.
- **읽기 누락**: 주입한 30 %는 실제 서보 무응답률(약 5~8 %, T1)의 4~5배라 감지가 대부분 멈췄다. 가짜 접촉은 없었다(모의 시험 200회+도 0). 실제 누락률(약 6 %)에서의 중단 빈도는 주입 시험으로 따로 재지 않았다(실제 닫기 15회는 모두 정상 감지였으므로 실제 조건에서는 드물다고 **추정**).
- **조임 유지**: 15회 중 1회가 4 펄스 움직였다(기준 3). 원인은 확인 못 함(큐브 미끄러짐/서보 데드밴드 후보). 유지 실패가 아니라 위치 변동이고 큐브를 놓치지는 않았다.
- 시험 중 그리퍼 서보 온도: 35~40 ℃에서 시작해 5회 닫기+조임 후 56~62 ℃까지 상승(80 ℃ 기준 아래). 시험 사이에 식힘.

## 결정 (제안 — 사용자 확인 후 확정)
1. 큐브 접촉 위치 창을 **[505, 545]**로 좁히는 것을 제안한다(관측 520~532에서 여유 약 +/-13~15; 손가락 최대 486과 19 펄스 간격). 근거 표본 n=15이고 한 물체·한 사람의 배치라서 **임시값**이다.
2. 위치 창만으로는 큐브를 보증하지 못하므로, 접촉 판정 뒤 **조임 유지 확인(2 s ±3)과 접촉 후 위치 변동**을 파지 성공 조건에 넣고, 창 밖 접촉·창 안이지만 유지 실패는 `FAILED`로 한다.
3. 감지가 `no_reading`으로 멈추면 재시도 정책(읽기 3회)을 유지한다.
4. 20/20 기준은 이 사람의 5회를 더 하거나(큐브 위치를 바꾸며) 기준을 15/15로 낮출지 결정이 필요하다. 이번에는 **충족했다고 쓰지 않는다**.
