## 고친 것
- **브리지 관절 신선도 오판**: 브리지는 "보고 때 age_s + 보고 후 경과"로 판단하는데 `arm/servo_stats`가 1 s 주기라, 위치 읽기 한 번 실패(age 0.55 s,
  실패율 3~6 %)만으로 다음 보고 직전 1.55 s → 한계 1.5 s 초과로 궤적 중단(매번 다른 서보, 움직이지 않는 관절 포함, 항상 "1.5s").
  joint5 왕복 진단에서 움직이는 서보의 실패 응답 0 → 가설("이동 중 응답 실패") 기각. `servo_stats_period_s` 0.2 s로 고침(한계 1.5 s는 유지).
- 시험 도구: 파지 실패 후 Idle까지 기다린 뒤 물러남. 온도 중단은 사용자 결정으로 끔(기록·75 ℃ 경고만).

## 온도 (중요)
관절 서보가 **홈 자세를 버티는 것만으로도** 오른다: 시험 시작 30~34 ℃ → 약 10분 뒤 servo 1·3이 70 ℃, 정지 상태에서도 1분에 약 1 ℃.
숙인 자세(pregrasp/grasp_floor)에서는 servo 2(어깨) 77~78 ℃, servo 3 77 ℃. 서보는 85 ℃에서 스스로 토크를 끊는다(팔이 처질 수 있음).
기준 "서보 < 80 ℃"는 이번 시험에서 아슬아슬하게 지켰지만 반복 시험(이름 자세 10회 등)에서는 넘을 가능성이 크다 → 쉬는 자세/토크 끄기 정책 필요.
