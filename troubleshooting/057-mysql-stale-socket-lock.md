# MySQL 소켓 잠금으로 서비스가 반복 재시작됨

- 증상: 2026-11-17 로컬 MySQL 연결 거부, systemd 재시작 반복. 로그는 소켓 잠금 PID 2319가 사용 중이라고 보고했다.
- 확인: PID 2319는 `sd-pam`이고 MySQL이 아니었으며 해당 Unix 소켓은 수신 중이 아니었다. 이전 소켓·잠금 파일이 남은 상태에서 PID가 다른 프로세스에 재사용된 것으로 판단했다.
- 복구: 서비스를 중지하고 오래된 소켓·잠금·PID 파일을 사용자 전용 `mysql-run/stale-20261117-1794841372/`로 보존한 뒤 재시작해 DB 접속을 확인했다. DB 데이터는 변경하지 않았다.
- 재발 방지: `tools/ops/prepare_mysql_socket.py`를 MySQL 서비스 시작 전 실행한다. 잠금 PID가 살아 있는 mysqld이거나 소켓에 연결되면 중단하며, 그렇지 않을 때만 파일을 별도 디렉터리로 이동한다. 오래된 잠금 보존 단위 시험과 실제 MySQL 서비스 재시작·임무 API 복구를 확인했다. 실제 시스템 재부팅 후 검증은 남았다.
