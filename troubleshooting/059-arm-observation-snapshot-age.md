# 팔 보정 자세 수집에서 서보 응답 미확인

- 증상: 실제 관절 6개와 서보 진단이 수신되지만 TCP 자세 캡처가 간헐적으로 `arm_feedback_unavailable`을 반환했다.
- 원인: ROS 모니터의 파일 스냅샷은 2초 간격인데 API는 스냅샷의 저장 후 경과까지 더해 서보 응답을 1.5초 미만일 때만 허용했다. 정상 서보 응답도 다음 스냅샷까지 기다리는 구간에 오래된 것으로 판정됐다.
- 수정: 모니터 파일 저장 주기를 0.5초로 줄였다. 기존 1.5초 응답 신선도 제한은 유지한다.
- 확인: 실제 센서 전용 팔 관측 모드에서 6관절 서보 응답을 확인하고, 구동 없이 실제 TF 자세 수집 함수를 3회 연속 성공했다. 가짜 시리얼에서는 팔 관측 모드의 위치·온도 읽기 외 구동 프레임 0과 센서 기본 모드 시리얼 출력 0을 확인했다. 실제 다중 자세 보정 정확도는 미검증이다.
