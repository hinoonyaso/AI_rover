# 036 — 자체 펌웨어 모터 첫 시험: 오른쪽 앞바퀴가 시험 후 안 멈추고 최대 속도로 계속 회전 (2026-10-10)

- 상태: **해결(코드)**, 실기 재확인 대기 — 엔코더 부호 수정 + 안전장치 2개 추가
- 관련: `firmware/rrc_m4`(`app/inc/app_config.h`, `lib/core/src/encoder_motor.c`, `app/src/tasks.c`),
  `tools/stm32_diagnostics/rrc_m4_raw_pwm_test.py`, troubleshooting/035(같은 날 브링업)

## 상황
`MOTOR_ENABLE=ON` 빌드, 바퀴 띄움, 모터 스위치 ON. RAW_PWM 진단 명령(PID 없이 PWM 직접, 0.5초 무명령 시 자동 해제)으로
바퀴 하나씩 ±400, 1초씩.
- M0 왼쪽 앞, M1 왼쪽 뒤: +PWM = 전진, 엔코더 카운트도 + (약 ±5,700/1초 구간). 정상.
- **M2 오른쪽 앞: +PWM에 엔코더 −11,204, −PWM에 +8,357(부호 반대, 크기도 큼). 시험이 끝난 뒤에도 바퀴가 빠르게 계속 회전**
  (사용자: "왼쪽은 일정한 속도, 오른쪽은 되게 빠르게"). e-stop(DIAG 0x02)·속도 0 명령을 보내도 6.2 rps 유지 → 모터 스위치 OFF로 정지.
- 그 순간 SWD로 읽은 TIM9 CCR1(PE5) = **1000(100 %)**, 다른 모터 채널은 0. PWM 핀 배정(M2 = TIM9)은 맞았다.

## 원인
1. **M2 엔코더 부호가 PWM과 반대**(`MOTOR_ENCODER_SIGN` 기본 +1). RAW_PWM 단계가 끝나 0.5초 뒤 속도 PID(목표 0)로 돌아가면,
   관성으로 도는 바퀴를 멈추려는 PID 출력이 반대 부호 때문에 오히려 가속 → 최대 PWM까지 양의 되먹임.
2. **폭주 감시의 사각지대**: 기존 가드는 `|목표| >= 0.3 rps`일 때만 동작 → 목표 0에서는 절대 래치되지 않음.
3. **e-stop이 정지를 유지하지 않음**: `robot_estop()`이 `enc_motor_stop()`으로 PWM을 한 번 0으로 만들지만,
   제어 태스크가 10 ms마다 PID(`enc_motor_control`)를 계속 돌려 곧바로 다시 출력.

## 해결
- ~~`MOTOR_ENCODER_SIGN {1, 1, -1, -1}`~~ → 최종: **M2 PWM 짝 교체 + 부호 {1,1,1,1}**(아래 "추가").
- **엔코더 부호 가드**(`ENC_MOTOR_SIGN_GUARD_*`): `|PWM| >= 600`인데 측정 속도가 반대 방향으로 `>= 1 rps`이고 감속하지 않는 상태가
  200 ms → RUNAWAY 래치. 목표 속도와 무관. 정상 반전(+4 → −4 rps)은 감속하므로 래치 안 됨. 호스트 시험 `test_enc_motor_sign_guard`
  (가드를 끄면 실패, 켜면 통과 — 실기 상황 재현 확인).
- **e-stop 유지**: 제어 태스크에서 `robot.estop`이면 매 주기 모든 모터 `enc_motor_stop()` + RAW_PWM 0, PID 건너뜀.
- 시험 스크립트: 단계 동안만 e-stop 해제, 단계 직후 e-stop → 단계 사이에 PID가 안 돈다. 종료 시 e-stop 상태로 둔다.

## 추가 (같은 날) — 진짜 원인은 M2의 PWM 핀 짝
부호 {1,1,-1,-1}로 다시 시험하니 M2는 정상이었지만 M3 카운트가 PWM과 반대(→ M3 원래 부호는 +1). 사용자 관찰:
M3는 +PWM에서 **뒤로**, M2는 +PWM에서 **앞으로**. 좌우 모터가 거울 장착이므로 오른쪽은 +PWM = 후진이 자연스럽고(vendor 규약:
오른쪽 바퀴 전진 rps 음수), M2만 PINMAP 추정 PWM 짝(TIM9 CH1 역/CH2 정)이 뒤바뀌어 있었다. M2 짝을 맞바꾸고 엔코더 부호를 전부 +1로 →
재시험: M2 +8,824/−8,947, M3 +9,019/−9,330, 오른쪽 두 바퀴 모두 +PWM에서 후진(사용자 확인), 시험 후 정지·e-stop 유지 정상.
M2의 −1 부호는 뒤바뀐 핀 짝을 보상했을 뿐이었다.

## 재발 방지
- 새 모터/배선은 **RAW_PWM으로 부호 확인 → 그다음 속도 제어** 순서를 지킨다(이번에 이 순서 덕에 바퀴 띄운 상태에서 잡혔다).
- 안전장치는 "목표가 있을 때"만이 아니라 "출력과 측정이 모순될 때"를 본다.
- 모터 시험 중에는 사람이 모터 스위치에 손을 둔다 — 소프트웨어 정지가 안 듣는 경우가 실제로 있었다.
