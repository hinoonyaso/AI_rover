# 032 — Nav2 시험 후 정지 상태에서 바퀴 "웅" 소리 (2026-10-07)

- 상태: **미해결** — 정지 프레임(0x03)은 바닥 울림을 멈추지 못함(폐기), 탭하면 멈춤
- 관련: 031(DWB가 데드존 아래 미세 명령을 수십 초 냄), `src/jetrover_base`

## 증상
Nav2 직진 시험 여러 번 뒤 로봇이 멈춘 상태(`/cmd_vel` 없음, base_node가 watchdog으로 속도 0 전송)에서
바퀴 쪽에서 소리가 계속 남. 바퀴를 손으로 살짝 톡 치니 멈춤. 이전에는 없던 소리(사용자).

## 원인 (추정)
- base_node의 정지는 속도 명령(FUNC3 서브커맨드 0x01) 0 rev/s뿐이다. 펌웨어는 엔코더 기반 속도 루프를 돌리므로
  목표 0에서도 멈춘(바닥에서 비틀린) 바퀴에 작은 PWM을 계속 걸 수 있다. 바퀴를 치면 엔코더가 바뀌어 루프가 다시 맞춰짐.
- 오늘 처음 들린 이유: DWB가 데드존 아래 명령(wz 0.02 rad/s 등)을 수십 초 내는 상황이 반복됐다(031).
- 바퀴를 띄운 상태에서는 0.02 rev/s × 15 s 후 속도 0으로도 **재현 안 됨** → 하중(바닥)이 필요한 현상으로 추정.

## 확인한 사실 (실기, 바퀴 띄움)
- 프로토콜 PDF의 "여러 모터 정지" 프레임 `AA 55 03 02 03 0F D3`(서브커맨드 0x03, 마스크 0x0F=모터 0~3)을
  이 펌웨어가 받아들이고 부작용 없음(STM32 계속 송신), 그 뒤 속도 명령(0.3 rev/s) 정상 동작(4바퀴 전진 확인).
- base_node 경로: `/cmd_vel` 0.05 m/s 2초 → watchdog 정지(속도 0 + 정지 프레임) 2회 반복, 오류 없음.

## 조치
- `rrc_protocol`: `build_motor_stop_packet(mask)` + 단위시험(실기에서 보낸 바이트와 동일).
- `base_node::stop_motors()`: 속도 0 다음에 정지 프레임도 전송. 파라미터 `motor_stop_frame_on_stop`(기본 true, `base.yaml`).
- 시험 도구: `tools/stm32_diagnostics/motor_stop_hum_test.py` (hum / zero / stopall / spin 단계).

## 재발 시
바닥에서 다시 소리가 나면 (base_node를 내리고) `motor_stop_hum_test.py stopall`로 즉시 멈추는지 확인 → 멈추면 원인/대책 확정.
멈추지 않으면 원인은 다른 것(예: 모터 드라이버 PWM 주파수 자체)이므로 이 문서를 갱신한다.

## 2026-10-07 23:30 바닥에서 재발 → 정지 프레임 시험: **효과 없음 (가설 폐기)**
- Nav2 시험 후 바닥에서 다시 울림. base_node를 내리고 `motor_stop_hum_test.py stopall` 전송 → **소리 안 멈춤**(사용자).
- 덧붙여 확인: Nav2는 주행 끝에 속도 0을 **명시적으로** 보내므로 base_node watchdog(움직이던 중 명령 끊김에만 동작)은
  정지 처리를 실행하지 않는다 — 즉 Nav2 종료 후엔 원래부터 `stop_motors()`가 안 불린다(동작상 문제는 아님, 속도 0은 전달됨).
- 프로토콜 PDF의 모터 서브커맨드는 0x00/0x01(속도), 0x02/0x03(정지)뿐이고 PWM duty 직접 제어가 없다 → 호스트에서 끌 수단 없음.
- 남은 추정: 펌웨어 속도 PID가 목표 0에서 기어 백래시 안에서 미세 진동(limit cycle). 정지 명령도 펌웨어 안에서 목표 0과 같게 처리되는 듯.
  탭하면 바퀴가 백래시 한쪽에 붙어 안정 → 조용해짐과 일치. 확인하려면 자체 펌웨어(firmware/rrc_m4)에서 정지 시 PWM 0/적분 리셋을 넣는 것이 근본 대책.
- 조치: `motor_stop_frame_on_stop` **기본 false**로 되돌림(코드/파라미터/단위시험은 남김). 당장의 우회: 바퀴를 살짝 치거나 로봇을 살짝 민다.
- 왜 오늘 처음 들렸나: 미확인. 오늘은 DWB가 데드존 아래 미세 명령을 오래 낸 시험이 많았다(031) — 바퀴가 비틀린 채 멈추는 빈도가 높았을 수 있음.
